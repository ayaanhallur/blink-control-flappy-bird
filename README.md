# blink-control-flappy-bird
Flappy Bird esque game where blinking makes you jump in game. When you lose the game, a vibrating armband delivers stimuli

Uses Muse 2 EEG Headset, PiShock collar, and PyGame library.

pishock branch is for PISHOCK COLLAR COMMITS
game branch is for COMMTIS FOR CODING THE GAME
muse branch is for COMMITS FOR THE HEADSET
